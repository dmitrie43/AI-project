# Лекция: Градиент простыми словами (Фаза F)

**Цель:** понять, *как модель «учится»*, без высшей математики.  
**Формат:** маленький шаг → картинка → код на Python.

Запускать демо:

```bash
cd C:\Docker\ai
python math-phase-f-gradient-demo.py
```

---

## 1. Вспомним: что такое loss

**Loss** = число «насколько модель сейчас ошибается».

- loss маленький → предсказания хорошие;
- loss большой → ошибается сильно.

Пример из жизни тикетов (упрощённо):

- факт: срочность = 5;
- модель предсказала 8;
- ошибка = 3;
- loss можно взять как `ошибка² = 9`.

Чем дальше от правды — тем больше loss.

---

## 2. Loss зависит от «крутилки» w

Представим, что у модели есть **одна** настройка — вес `w` (как громкость на колонке).

От `w` зависит предсказание → от предсказания зависит loss.

Значит, есть функция: **какое `w` → какой loss**.

Самый простой учебный пример (не реальные тикеты, а игрушка):

```
loss(w) = (w - 3)²
```

То есть:

- если `w = 3` → loss = 0 (идеально);
- если `w = 5` → loss = 4;
- если `w = 0` → loss = 9.

### Картинка

```
loss
  9 | *
  4 |   *       *
  1 |     *   *
  0 |       *
    +--------------- w
            3
         минимум
```

Низ «чаши» в точке `w = 3`.  
**Обучение** = найти такое `w`, где loss минимальный (здесь это 3).

В реальной модели крутилок тысячи (`w1, w2, ...`), но идея та же: спуститься на дно чаши.

---

## 3. Зачем не перебирать все w

Можно тупо проверить w = 0, 0.1, 0.2, ... — долго.

Умнее: встать в случайной точке на склоне и **шагать вниз**, пока не окажетесь у дна.

Для этого нужно знать: *сейчас склон идёт вверх вправо или влево?*

Ответ даёт **градиент**.

---

## 4. Градиент — «стрелка вверх по склону»

На нашей игрушке:

```
loss(w) = (w - 3)²
градиент(w) = 2 * (w - 3)     # насколько крутой склон и куда
```

(Откуда формула — пока не важно. Важно поведение.)

| Сейчас w | Градиент | Смысл | Куда идти вниз |
|----------|----------|--------|----------------|
| w = 5 | 2*(5-3)=**+4** | склон вверх направо | уменьшить w (влево) |
| w = 1 | 2*(1-3)=**-4** | склон вверх налево | увеличить w (вправо) |
| w = 3 | 0 | дно | почти не двигаться |

Правило обучения одной строкой:

```
w_новое = w_старое - learning_rate * градиент
```

Минус = идём **против** стрелки градиента = **вниз**.

### Аналогия

Вы в тумане на холме.  
Градиент говорит: «в эту сторону вгору».  
Вы делаете шаг в противоположную сторону.

---

## 5. Learning rate — длина шага

`learning_rate` (часто `lr`) — насколько большой шаг делаем.

```
w = w - lr * градиент
```

### lr слишком маленький (например 0.01 при большом расстоянии)

- шаги крошечные;
- до дна идти очень долго;
- в логах loss почти не меняется.

### lr нормальный (например 0.1 в нашем демо)

- стабильно спускаемся к минимуму.

### lr слишком большой (например 2.0)

- перескакиваем дно;
- прыгаем с одного склона на другой;
- loss скачет: 9 → 25 → 9 → 25...

```
Нормальный lr:     * --> * --> * --> *   (к центру)

Большой lr:        * --------> * <-------- * --------> *
                   (перелёт через минимум)
```

---

## 6. Весь алгоритм в 4 шагах

Повторяем много раз (эпохи / итерации):

1. Взять текущий `w`.
2. Посчитать `loss` и `градиент`.
3. Обновить: `w = w - lr * градиент`.
4. Снова пункт 1.

Это и есть **градиентный спуск**.

В sklearn / нейросетях цикл спрятан внутри `fit()` / `train()`, но смысл тот же.

---

## 7. Пример с кодом (игрушка)

Файл: `math-phase-f-gradient-demo.py`

Идея кода:

```python
def loss(w: float) -> float:
    return (w - 3.0) ** 2

def gradient(w: float) -> float:
    return 2.0 * (w - 3.0)

w = 8.0          # старт далеко от идеала 3
lr = 0.1         # длина шага

for step in range(30):
    g = gradient(w)
    w = w - lr * g
    print(step, "w=", round(w, 3), "loss=", round(loss(w), 3))
```

Что увидите: `w` постепенно идёт к **3.0**, `loss` падает к **0**.

Потом в том же файле прогоняются:

- маленький `lr` → медленно;
- большой `lr` → скачет / разлетается.

Запустите и сравните три таблицы в выводе.

## 8. Связь с реальной моделью тикетов

Игрушка была с одним `w`. В реальности:

```
y ≈ w1*x1 + w2*x2 + ... + b
```

У каждого веса свой «склон». Градиент говорит, **каждый** вес чуть увеличить или уменьшить, чтобы loss на train упал.

После многих шагов:

- train loss обычно падает;
- если слишком долго крутить сложную модель → overfitting (фаза E): на train отлично, на val плохо.

Поэтому смотрят val и делают early stopping — не потому что градиент «плохой», а потому что цель «минимизировать train loss» можно переусердствовать.

## 9. Temperature vs learning rate (чтобы не путать)

| Параметр | Когда | Что крутит |
|----------|--------|------------|
| **temperature** | уже готовая LLM, генерация текста | случайность следующего слова |
| **learning rate** | обучение модели | размер шага при обновлении весов |

Разные этапы жизни модели.

## 10. Шпаргалка на собес (30 секунд)

> Loss — ошибка модели. Она зависит от весов.  
> Градиент показывает, в какую сторону loss растёт.  
> Мы обновляем веса в противоположную сторону — это градиентный спуск.  
> Learning rate — размер шага: слишком маленький — медленно, слишком большой — перескакиваем минимум и loss скачет.
