# оСМатематика для AI / GenAI Engineer

План **под вашу профессию и 90-дневный календарь**, не «вся высшая математика».  
Цель: уверенно объяснять RAG, эмбеддинги, метрики качества и лёгкий tabular ML на собесе и в пилоте.

**Принцип:** сначала бумага/голова → потом `py-vector-lab` / `data-pipeline` / код пилота.

Ориентир нагрузки: **3–5 ч/нед** параллельно основному плану (или блоками по 1–2 недели до н.5).

## Фаза B — Метрики качества (обязательно до eval пилота)

**Зачем:** н.4 ML metrics, н.8–9 retrieval/answer eval, разговор с менеджером «70% полезных».

### Темы

1. Confusion matrix intuition: TP / FP / FN / TN
2. **Precision** = TP / (TP+FP) — «из того что нашли, сколько правды»
3. **Recall** = TP / (TP+FN) — «из всей правды, сколько нашли»
4. **F1** — гармония precision/recall
5. **Accuracy** — когда врёт (дисбаланс классов)
6. **Hit-rate@k / Recall@k** для retrieval
7. Baseline «всегда majority class» — лекция: [`math-phase-b-baseline-lecture.md`](math-phase-b-baseline-lecture.md)
8. Leakage / train-val — лекция: [`math-phase-b-leakage-lecture.md`](math-phase-b-leakage-lecture.md)

### Задачи

- [x] B1. Таблица: 100 тикетов, 90 resolved. Модель всегда говорит resolved. Accuracy? Почему это плохой baseline-обман?  
- [x] B2. Retrieval: из 10 вопросов в top-5 попал нужный doc у 7. Hit-rate@5 = ?  
- [x] B3. Spam-фильтр: лучше высокий precision или recall? (и наоборот для «не пропустить поломку VPN в runbook»)  
- [x] B4. Написать 5 своих golden-вопросов к вымышленной wiki и ожидаемый doc-id (тренировка мышления eval).  
- [x] B5. Прочитать `data-pipeline` report.md: что такое baseline 73% resolved своими словами.

**Критерий фазы B:** отличаете precision/recall и hit-rate@k; не путаете accuracy с качеством RAG.

## Фаза C — Вероятность и «неуверенность» (лёгкий слой)

**Зачем:** temperature LLM, softmax в классификаторах, «модель не уверена», calibration на пальцах.

**Лекция:** [`math-phase-c-probability-lecture.md`](math-phase-c-probability-lecture.md)

### Темы

1. Вероятность 0..1, сумма исходов = 1
2. Независимость «на пальцах»
3. Матожидание ≈ среднее
4. Дисперсия / разброс (интуиция)
5. Softmax: из сырых чисел → вероятности
6. Temperature: выше → распределение «более плоское»
